# Superstore Sales Dashboard — End-to-End Analytics Project

## Tech Stack
Excel, SQL, Python (Jupyter Notebook), Tableau

## Dataset
The project is built from the supplied Superstore workbook.
- 9,994 order-line records
- 5,009 unique orders
- 793 customers
- Date range: 2014-01-03 to 2017-12-30
- Returned orders: 296 (5.91%)

## Folder Structure
- `data/` — cleaned CSV files for Python, SQL and Tableau
- `excel/` — formula-driven Excel analysis workbook
- `sql/` — reusable analytical SQL queries
- `python/` — Jupyter notebook with reproducible EDA and insights
- `tableau/` — packaged Tableau workbook + source CSV
- `Superstore_Sales_Analysis.xlsx` — Excel deliverable (copy also placed in `excel/`)

## Key Business Insights
- West is the largest region by sales and profit.
- Technology has the strongest category-level profit margin.
- Furniture has a much lower margin than Technology and Office Supplies.
- Tables and Bookcases are loss-making sub-categories.
- Heavy discount levels, especially 70%–80%, show strongly negative profitability.
- Consumer is the largest customer segment by sales.
- Returned orders are approximately 5.9% of all orders.

## Portfolio Story
This project demonstrates an end-to-end analytics workflow: data preparation → KPI analysis → SQL business questions → Python EDA → interactive dashboard storytelling.
